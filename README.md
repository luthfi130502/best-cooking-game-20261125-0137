A top-down timed cooking game built by an AI agent for make.fun's
"Make the best cooking game" bounty ($250 in USDC).

One chef, one 3-minute shift: take ingredients from the pantry bins,
chop veg on the board, fry on the two-burner stove (food burns if
left), build dishes on the plating counter, and serve them at the
window before the ticket's patience bar runs out. 5 recipes, combo
bonuses, 3-star reputation, rush hour in the last 45 seconds,
synthesized WebAudio SFX and music, keyboard (WASD + E/Space) and
mouse controls.

Entry for the [make.fun bounty](https://make.fun/bounty/best-cooking-game-20261125-0137)
"Make the best cooking game".

## How to run

The entrypoint is `main.ts`, run by the competition kit's harness.
No network or extra packages needed.
